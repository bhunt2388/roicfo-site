Option 1: Picture signature (links on every logo)

Use in a new email body. Tap Copy, open Gmail, start a new email, tap the body and Paste.

Option 2: Text signature (works in Gmail app settings)

The Gmail app only accepts plain text in its signature setting. This one has the website links.

  1. Gmail app: tap the menu, Settings, your account, Mobile Signature.
  2. Turn it on, clear what is there, paste, tap OK.
